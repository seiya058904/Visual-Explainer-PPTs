# Deck 03 · 玻璃：透明是一场能量的错身而过

> 选题slug（建议）：`glass-why-it-is-transparent`
> 状态：文案待审阅

## 认知缺口

流行解释 1：「玻璃透明，是因为它很干净 / 什么都没挡」。
准确解释 1：透明是因为玻璃的电子不吸收可见光——光子的能量不足以被"消费"，于是穿了过去。紫外线的能量够，就会被吸收。
流行解释 2：「老教堂的玻璃在缓慢流动，所以下厚上薄」。
准确解释 2：玻璃是无序固体，不会流动；厚度不均来自中世纪的制造工艺。
