# Deck 01 · 空调：冷是一种被搬运的状态

## 认知缺口

流行解释：「空调吹出冷气，把房间变冷」。
准确解释：冷不是一种实体，空调的全部工作是**搬运热**——把室内的热搬到室外，顺便拧干空气里的水分。搬运要付电费，而且搬运规模正在变成全球电力问题。
