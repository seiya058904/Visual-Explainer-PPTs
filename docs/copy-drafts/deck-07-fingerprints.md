# Deck 07 · 指纹：皮肤上最著名的误解

> 选题slug（建议）：`fingerprints-friction-was-not-the-point`
> 状态：文案待审阅

## 认知缺口

流行解释：「指纹是为了增加摩擦、防止打滑演化出来的」。
准确解释：这一说法长期缺少证据，实验反而提示脊线**减小**接触面积、未必增加摩擦。更受支持的功能假说是排水与精细触觉感知；而它如今最重要的角色——身份识别——完全是文化的再利用。
第二层缺口：「指纹人人不同」与「指纹比对绝对可靠」是两回事。
