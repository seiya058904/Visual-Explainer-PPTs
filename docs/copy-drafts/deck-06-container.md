# Deck 06 · 集装箱：改变世界的不是船

> 选题slug（建议）：`container-the-box-that-unified-interfaces`
> 状态：文案待审阅

## 认知缺口

流行解释：「全球化靠的是更大的船、更快的引擎」。
准确解释：航运革命的真正杠杆是**标准化**——1956 年后，一个铁盒子统一了船、吊机、卡车、火车的接口，装卸成本下降约两个数量级。船没有变快，接口统一了。
