# Deck 10 · 桥梁：它从来不是静止的

> 选题slug（建议）：`bridges-always-moving`
> 状态：文案待审阅

## 认知缺口

流行解释 1：「桥是被重量压垮的，所以越结实越好」。
准确解释 1：桥的工作不是"扛住"，是**导力**——把每一分荷载沿压、拉路径送到大地。材料问题之外，真正的杀手常常是运动：风致颤振、人致共振。
流行解释 2：「塔科马大桥是被'共振'吹垮的」——教科书曾这么说，后来被修正为气动弹性颤振。
