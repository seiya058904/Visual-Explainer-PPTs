# Deck 04 · 咖啡因：它没有给你能量

> 选题slug（建议）：`caffeine-blocking-sleepiness`
> 状态：文案待审阅

## 认知缺口

流行解释：「咖啡给我能量 / 咖啡因提神」。
准确解释：咖啡因不产生任何能量，它只是**挡住"困"的信号**——冒充腺苷坐进受体，让大脑暂时收不到疲劳广播。账没有消失，只是被藏起来了。
