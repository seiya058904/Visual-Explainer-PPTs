# Deck 02 · 肥皂：把油污拆成能冲走的碎片

> 选题slug（建议）：`soap-the-molecule-that-translates-oil`
> 状态：文案待审阅

## 认知缺口

流行解释：「肥皂能杀菌消毒」。
准确解释：肥皂的主要工作是**物理移除**——把不溶于水的油污（以及藏在油污里的细菌、病毒包膜）拆成能被水冲走的小碎片。它大多数时候不是杀手，是搬运工。
