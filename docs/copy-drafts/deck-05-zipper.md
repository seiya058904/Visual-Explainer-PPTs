# Deck 05 · 拉链：一行可以开合的牙齿

> 选题slug（建议）：`zipper-a-line-of-teeth`
> 状态：文案待审阅

## 认知缺口

流行解释：「拉链靠摩擦把两边夹在一起」。
准确解释：拉链不靠夹持，靠**几何互锁**——每一对齿的凸起嵌入对方的凹槽，拉力被分配到整条链上。它是把一排单独的弱点，锁成一条共同的结构。
第二层缺口：这项发明落地后约二十年无人问津——好发明不等于好产品。
