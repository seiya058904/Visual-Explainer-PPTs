# Visual Explainer Library

## Platform
Web, static GitHub Pages project site.

## Product truth
User-approved implementation brief: 38 Approved Chinese interactive HTML presentations, 10 Pending candidates. Readers explore knowledge visually, search by Chinese/English subject and open a complete independent presentation. Maintainers use one catalog, reproducible exports, screenshots and tests. Pending never appears in the public artifact. Existing presentation URLs and runtime capabilities must survive.

## Stack
User-approved plan: static HTML/CSS/JavaScript generated with Python, Node browser tooling. No backend. GSAP only for a short optional entrance. Real deck captures are the only gallery previews.

## Success
All 38 published works discoverable; no eager deck HTML loads; accessible mobile navigation; truthful per-deck audit status. Candidate approval remains a user decision. No invented performance, licensing or endorsement claims.
