# Gallery design

Approved direction: editorial gallery, warm paper and ink, real presentation imagery, six selected works and complete searchable index. Experience mode: the artifacts lead, navigation recedes. Preserve each deck identity. This authority applies only to the gallery, never to deck templates.

Use a bookish serif headline with a practical sans UI, pale paper, oxblood accent, hairline separators. Hero is a large typographic introduction beside a real frame; selected works use varied scale, library uses compact image-led rows. No decorative statistics, card shadows, stock images, scroll hijacking or hidden-on-load content. All controls have immediate focus, minimum 44px targets, keyboard support and reduced-motion fallback.

Hallmark and Impeccable inform craft; the user already approved product/stack/direction in the implementation plan, so no repeat interview or competing design-selection flow. Actual screenshot inspection precedes final selection and final visual acceptance.
